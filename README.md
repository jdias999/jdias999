## Sobre mim

Sou estudante de **Análise e Desenvolvimento de Sistemas** e estou direcionando meus estudos para **Engenharia de Dados**.

Minha base vem do desenvolvimento de software, mas atualmente estou focado em entender melhor todo o caminho que os dados percorrem: desde a extração de uma API ou banco de dados, passando por limpeza e transformação, até o armazenamento e consumo para análises.

Tenho estudado principalmente **Python e SQL**, e venho colocando esses conhecimentos em prática através de projetos próprios.

Meu objetivo é chegar ao mercado de estágio com uma boa base dos principais conceitos de Engenharia de Dados, além de experiência prática com ferramentas utilizadas no dia a dia da área.

---

## O que estou estudando

Atualmente, meu foco está em construir uma base sólida nos seguintes pontos:

- Python para manipulação e processamento de dados;
- SQL e modelagem de bancos de dados;
- ETL e ELT;
- APIs e ingestão de dados;
- PostgreSQL e outros bancos relacionais;
- Pandas;
- Apache Spark e PySpark;
- Databricks e Delta Lake;
- Arquitetura Medallion;
- Apache Airflow para orquestração;
- Microsoft Azure e serviços voltados para dados;
- Git e GitHub;
- Visualização e análise de dados com Power BI.

A ideia não é apenas aprender a sintaxe das ferramentas, mas entender **por que e quando cada uma delas é utilizada dentro de um pipeline de dados**.

## Projetos

### [SAC ANAC — Pipeline ETL & Análise](https://github.com/jdias999/aviation-complaints-analytics-pipeline)

Pipeline de dados construído a partir de dados públicos da ANAC e do SAC.

O projeto envolve ingestão, limpeza, transformação e análise de mais de 100 mil registros, utilizando **Python, Pandas, SQL e DuckDB**.

O objetivo foi transformar dados brutos em informações que pudessem ser utilizadas para analisar reclamações, categorias e indicadores relacionados ao atendimento.

---

### [Data Warehouse & Medallion Architecture](https://github.com/jdias999/data_warehouse_jobs)

Projeto voltado para a construção de um **Data Warehouse** utilizando a arquitetura **Medallion**, dividindo o fluxo de dados nas camadas Bronze, Silver e Gold.

A ideia é praticar desde a chegada dos dados brutos até a criação de estruturas mais organizadas para consultas e análises utilizando SQL.

---

### [Data Engineering Lab](https://github.com/jdias999/data_engineer_lab)

Repositório onde concentro estudos, exercícios e projetos menores relacionados à Engenharia de Dados.

Aqui ficam práticas de **SQL, Python, ETL, APIs, Pandas, PySpark, Spark e Databricks**, além de experimentos com diferentes ferramentas que fazem parte do ecossistema de dados.
